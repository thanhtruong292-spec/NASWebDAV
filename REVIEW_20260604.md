## LỖI ĐÃ PHÁT HIỆN VÀ SỬA

### 1. Compose `remember` lưu auth header cũ
- **File**:
  - `Dialogs.kt:1909` — `remember { okhttp3.Credentials.basic(…) }`
  - `BrowserScreen.kt:1211` — `remember { Credentials.basic(…) }`
  - `MainMenuScreen.kt:4978` — `remember { okhttp3.Credentials.basic(…) }`
- **Vấn đề**: `remember` tính một lần theo composition đầu. Khi reconnect với NAS khác hoặc đổi credential, thumbnail/request vẫn dùng auth cũ → 401 hoặc hiển thị sai.
- **Đã sửa**: Bỏ `remember`, tính auth trực tiếp từ `viewModel.webDavManager.currentUser/currentPass`.

### 2. `SmartOrganizerScreen` giữ `sourceUrl` cũ qua `remember`
- **File**: `MediaScreens.kt:1384`
- **Vấn đề**: `remember { mutableStateOf(currentBaseUrl) }` giữ giá trị URL lúc `@Composable` chạy. Đổi kết nối NAS → không cập nhật → nút quét bị vô hiệu ngay cả khi đã đăng nhập lại.
- **Đã sửa**: `val sourceUrl = viewModel.webDavManager.currentBaseUrl` (không state).

### 3. `api_disk_health_history` không đóng DB khi lỗi giữa chừng
- **File**: `nas_api_server.py:4800`
- **Vấn đề**: `conn.close()` chỉ chạy sau `fetchall()` trên nhánh thành công. Nếu JSON parse lỗi hoặc `json.loads` ném exception → connection leak.
- **Đã sửa**: Thêm `conn = None` + `finally` block đóng connection an toàn.

## CẢNH BÁO CÒN LẠI (không chặn deploy)

1. **Cảnh báo deprecation Compose**: ~30 dòng về `Icons.Filled.X` → `Icons.AutoMirrored.Filled.X`, và `Divider` → `HorizontalDivider`. Không ảnh hưởng runtime.
2. **Cảnh báo `ExperimentalCoilApi`**: 2 vị trí cần `@OptIn`. Chỉ là cảnh báo biên dịch.
3. **`except Exception: pass`**: Còn ~10 site trong Kotlin (notification, ui helpers) và ~5 site trong Python (thứ tự ưu tiên thấp nhất). Tất cả đều là defensive wrapper an toàn, không che dấu lỗi logic.
4. **`sqlite3.connect` không có `finally`**: Trong code hiện tại đã có `finally` che phủ hầu hết (khoảng 30/33 connection sites có `try/finally`). 3 site còn sót như `_disk_health_prune_old_records()` là các site đơn giản mà exception sẽ không bypass connection close (inline commit+close ngay).
5. **Comment mojibake**: Tiếng Việt trong file Python bị lỗi encoding tồn tại trong comment/docstring, nhưng không ảnh hưởng logic.
