## Findings con lai

### HIGH - Functional

#### F1. Android cleartext config hardcode hai IP

- `app/src/main/res/xml/network_security_config.xml:3-9`
- HTTP chi duoc phep toi `192.168.100.254` va `100.90.135.102`.
- UI va logic URL cho phep nhap cac dia chi LAN/Tailscale hop le khac, nhung
  Android se chan cleartext truoc khi request toi NAS.
- Doi router, subnet, DHCP lease hoac Tailscale IP co the lam app login that bai
  voi loi kho chan doan.

**Verdict:** nen sua ngay. Voi app NAS ca nhan, doi thanh:

```xml
<base-config cleartextTrafficPermitted="true" />
```

la trade-off hop ly. App da gioi han URL WebDAV HTTP vao LAN/Tailscale.

### MEDIUM - Fix chua hoan tat

#### F2. Ket qua luu credential van bi caller bo qua

- `NasApplication.kt:482`: `saveCredentials()` da tra `Boolean`.
- `WebDavViewModel.kt:4472,4620,4674`: caller khong kiem tra ket qua.

Neu Android Keystore/EncryptedSharedPreferences loi, login/revert van tiep tuc
nhu da luu thanh cong. Fix M5 moi chi them log va return value, chua thay doi
hanh vi caller.

**Verdict:** nen sua, nhung khong phai blocker neu thiet bi hien tai luu
credential binh thuong.

#### F3. Guest-pass state persist ca password plaintext

- `nas_api_server.py:10684-10706`
- File `/etc/nas/state/guest_passes.json` dang luu toan bo metadata, gom password.
- Reconcile/watcher chi can username va `expires_at`; khong can password.
- Code khong ep permission file thanh `0600`.

**Verdict:** bo field password khoi state persist, hoac it nhat `chmod 0600`.
Trong LAN ca nhan day la hardening nho, khong phai blocker.

### LOW - Residual risk chap nhan duoc

#### F4. Trust-by-IP van co the thanh permanent whitelist

- `authorized_ips` da co TTL mac dinh 7 ngay.
- Tuy nhien `/api/auth/authorize` van dua IP vao `_lan_whitelist` va iptables
  ACCEPT ben vung, nen TTL khong ap dung cho IP da qua handshake nay.

**Verdict:** chap nhan duoc neu LAN/Tailscale va cac thiet bi deu do ban kiem
soat. Can hieu ro day la trusted-device/trusted-network model, khong phai
per-request authentication model.

#### F5. Social extractor WebView hardening moi la mot phan

- Host input va URL tai `onPageFinished` da duoc allowlist chinh xac.
- JS bridge van duoc add ngay tu dau; redirect page co the chay script truoc
  `onPageFinished`.

**Verdict:** rui ro thap trong use case ca nhan va bridge co quyen han han che.
Khong can uu tien truoc F1/F2.
